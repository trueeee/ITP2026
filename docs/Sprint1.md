# Sprintplan – Sprint 1

## Sprint: 1 (datum: 23 maj 2026 – 25 maj 2026)

Skapa projektets grundstruktur, databas och användarhantering så att användare kan registreras och administreras.

### Backlog för sprinten
| Issue | Beskrivning | Ansvarig | Estimat | Klart-kriterium |
|------|-------------|----------|---------|-----------------|
| #1 | Skapa databasmodeller | Teamet | S | Tabeller skapas korrekt |
| #2 | Implementera användarhantering | Teamet | M | Användare kan skapas och tas bort |
| #3 | Skapa grundläggande UI | Teamet | S | Sidor kan navigeras |

### Risker att bevaka i sprinten
- Problem med databasuppkoppling.
- Otydlig datamodell.

### Definition of Done (check)
- [ ] DoD uppdaterad (om behov)

- [ ] Demo planerad

- Visa skapande och borttagning av användare.
